# 步数截图生成器 · 设计方案 v0

> 目标：本地网页工具，按日期范围批量生成「运动 App 今日步数页 / 历史步数页」截图，步数与各项运动指标可控且自洽。
> 说明：产物用于个人娱乐、UI 复刻练习与测试，请勿用于伪造证明材料或平台刷量。

---

## 1. 交付形态

一个**纯前端单页应用**，本地 `pnpm dev` 打开即用，无后端、无账号、不联网（首次安装依赖除外）。

```
┌───────────────────────────────┬──────────────────────────────┐
│ 控制台                         │  预览舞台                     │
│  · 日期范围 [起]—[止]          │   ┌──────────┐               │
│  · 每日步数 [min]—[max]        │   │ 393×853  │  今日 / 历史  │
│  · 目标步数 10,000             │   │ 手机画布  │  实时切换     │
│  · 随机种子 (可选)             │   └──────────┘               │
│  · 导出尺寸 / 格式             │  ──────────────────────────  │
│  [生成预览]                    │  缩略图网格：逐日预览/重掷/单张导出│
│  [导出全部 ZIP]                │                              │
└───────────────────────────────┴──────────────────────────────┘
```

关键流程：填参数 → 生成 `N` 条日记录 → 逐日判断模板（**日期 == 今天 → 今日页；其余 → 历史页**）→ 离屏渲染 1179×2560 → 逐张下载或打包 ZIP。

## 2. 技术栈

| 选择 | 理由 |
|---|---|
| **Vue 3 + Vite + TypeScript** | 两页是「大段静态结构 + 少量变量」，SFC 的 template/scoped style 与参考图的对应关系最直观；scoped CSS 隔离两页同名类，适合像素级还原 |
| 模板 = DOM + CSS 绝对定位 | 比 Canvas 逐笔绘制更好维护、更好对齐参考图，改一个圆角不用重算布局 |
| 导出 `html-to-image`（toPng） | 浏览器内把 DOM 转 PNG，无需服务端；`pixelRatio` 控制倍率 |
| `jszip` + 原生下载 | 批量打包，不引入额外服务 |
| 字体：内置 PingFang 风格开源字体（HarmonyOS Sans SC / MiSans，子集化） | 参考图是 PingFang 风格；Windows 默认微软雅黑差异明显，内置字体是「还原」的关键 |

**为什么是 Vue 而不是 React**：本项目 90% 的工作量在「把两张图 1:1 写成 HTML/CSS」，框架只负责表单状态和列表渲染。Vue SFC 把结构、样式、逻辑放在一个文件里，改一个卡片不用在 JSX 与 CSS Module 之间来回跳；`<style scoped>` 天然避免「今日页 .card」和「历史页 .card」互相覆盖——这在像素级还原里很常见。产物 gzip 后约 40KB，Vite 构建即静态文件。若你更熟 React 也可 1:1 迁移，仅模板外壳不同。

**部署**：`vite build` 输出 `dist/`，`base: './'` 让 `index.html` 可被任意静态托管（Nginx/OSS/GitHub Pages）直接访问，也能本地双击打开；所有生成与导出都在浏览器内存里完成，**不上传、不存储任何数据**。

**画布尺寸**：参考图 1179×2560 = 393×853.33 逻辑像素 @3x。模板按 393×853.33 布局，导出 `pixelRatio: 3`，得到与参考图逐像素同尺寸的 1179×2560 PNG。

## 4. 数据模型与换算

一条日记录：

```ts
type DayRecord = {
  date: string;          // 2026-05-01
  steps: number;         // 用户区间内随机
  goal: number;          // 默认 10000
  calories: number;      // round(steps * 0.0295 * k1)   k1 ∈ [0.92, 1.08]
  distanceKm: number;    // steps * 0.714 * k2 / 1000    k2 ∈ [0.92, 1.08]
  hourly: number[24];    // 24 小时分布，总和 = steps
  activeHours: number;   // 活动小时数 (0–6)
  exerciseMinutes: number; // 锻炼时长 (0–25)
  // 今日页附加（随机 + 联动）
  sleepText: string;     // 5小时41分
  heartRate: number;     // 104
  workoutKm: number;     // 运动记录 0.42 公里
};
```

换算系数由参考图反推：`258 kcal / 8742 步 = 0.0295`；`6.24 km / 8742 步 = 0.714 m/步`。今日页 `8 kcal / 282 步 = 0.0284`，与上式一致（取整误差）。按你的选择，实际生成时热量与距离各乘一个 `0.92–1.08` 的独立随机系数（每天重新抽取），避免每天数值呈现完美线性、更像真实记录。

### 24 小时分布

不用纯随机（会像噪声），用「作息权重曲线」：`00–06` 极低、`07–09` 通勤峰、`12–13` 午间峰、`17–19` 晚间峰、其余低权重，按权重分配总数并做 ±20% 抖动，保证 `Σ hourly = steps`，柱高按 `max(hourly, 2000)` 归一。

## 5. 随机与可复现

- `mulberry32(seed)` 种子随机；同参数 + 同种子 = 同结果（方便反复调参）。
- 步数：`min + floor(rand() * (max - min + 1))`，默认 min=3000 / max=15000。
- 「重掷」单日、整批重掷两种粒度；允许手动改写某天步数。

---

## 6. 导出

- 离屏挂载模板（`position: fixed; left: -9999px`），等 `document.fonts.ready` 后 `toPng(node, { pixelRatio: 3, width: 393, height: 853.33 })`。
- 文件命名 `steps-2026-05-01.png`；批量时串行渲染（避免内存峰值），显示进度条；结束打包 `steps-2026-05-01_2026-05-30.zip`。
- 文字长度自适应：步数 5 位数（如 12,345）时自动缩字号，避免撑破「282/10,000步」与进度条。

## 9. 已确认决策

| 项 | 决定 |
|---|---|
| 技术栈 | Vue 3 + Vite + TypeScript，纯前端运行时，构建产物为静态文件（可本地打开 / 静态托管） |
| 数据流 | 全部在浏览器内存中生成与导出，无后端、不上传、不落库 |
| 导出尺寸 | 1179×2560（与参考图一致，393×853.33 @3x） |
| 今日页其他卡片 | 运动记录（距离 + 轨迹）、减脂、睡眠、心脏健康全部随机，并与当日步数联动 |
| 指标换算 | 固定系数 0.0295 千卡/步、0.714 米/步，叠加 ±8% 随机浮动 |
| 模板分配 | 日期 == 今天 → 今日页；其余日期 → 历史页 |
| 状态栏 | 时间在 08:00–22:00 间随机、电量 85–99%，同一批内各不相同（如需固定可后续加开关） |

## 10. 风险与对策

| 风险 | 对策 |
|---|---|
| 中文字体不一致导致「不像」 | 内置开源 PingFang 风格字体，按模板固定文案子集化（约 100 字，体积可控）；导出前 `document.fonts.ready` |
| `html-to-image` 对个别 CSS 支持差（滤镜/混合模式） | 模板禁用 `filter/backdrop-filter`，一律用纯色与渐变实现 |
| 大批量导出内存峰值 | 串行渲染、及时释放 canvas、可选分卷下载 |
| 5 位数步数撑破布局 | 数字区自动测量宽度缩放字号 |
